# PET 알갱이에서 투명 컵까지

[데모 바로 열기](https://kn0831-gyu.github.io/pet-sheet-to-cup/)

PET 압출 현장의 경험을 바탕으로 만든 랜딩톤 출품작입니다. PET 알갱이가 한 장의 시트가 되고, 그 시트가 투명 컵이 되는 과정을 한 페이지에서 따라갑니다.

## 체험 방법

1. **전체 공정 보기**에서 생산라인을 가동하거나 설비를 눌러 상세 화면으로 이동합니다.
2. **호퍼**에서 새 PET와 재생 PET 비율을 바꿉니다. **T-DIE · 냉각롤**에서는 첫 롤 사이의 간격을 조절하고, 통과한 시트 두께를 비교합니다.
3. **롤 권취**에서 시트를 감습니다. 선택 체험에서 장력과 롤 외경을 바꾸면 시트 처짐과 바닥 접촉 여부가 달라집니다.
4. **이 롤로 컵 만들기**를 누르면 롤 이동, 시트 풀림과 가열, 금형 성형, 컵 적층을 차례로 볼 수 있습니다.

## 계산하는 것과 예시로 보여주는 것

- **두께:** 시트 폭과 공급량이 일정하다고 가정하고 롤 간격에 따른 통과 두께와 이송 속도를 계산합니다.
- **장력:** 두께 0.70 mm의 시트 모형에 중력과 장력을 적용해 처짐과 바닥 접촉 여부를 계산합니다. 일정 장력과 롤이 커질수록 목표 장력이 낮아지는 테이퍼 장력을 비교할 수 있습니다. 실제 설비 설정값을 제시하거나 시트 파단·지관 변형을 예측하지는 않습니다.
- **배합과 냉각:** 색과 흐림의 변화는 공정을 설명하기 위한 시각적 예시이며, 재료의 품질이나 투명도를 예측하는 계산은 아닙니다.

## 제작과 실행

현장 경험을 바탕으로 설비 순서와 시트 이송 경로를 정했습니다. ChatGPT는 공정 시각화, 상호작용과 계산 모형 구현, 데스크톱·모바일 동작 검수에 활용했습니다. 페이지 자체는 AI 호출 없이 브라우저에서 실행됩니다.

HTML·CSS·JavaScript와 SVG·Canvas를 `index.html`에 담았습니다. 설치나 빌드 없이 파일을 브라우저에서 열 수 있습니다.
